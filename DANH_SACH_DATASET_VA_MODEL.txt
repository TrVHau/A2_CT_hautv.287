CHI TIẾT 09 MÔ HÌNH DỰ ĐOÁN LÂM SÀNG:
--------------------------------------------------------------------------------

1. MÔ HÌNH 1: TabResNet with Self-Attention (Học Sâu Hiện Đại Cho Dữ Liệu Bảng)
   - Tệp lưu trữ   : project01/models/diabetes_tabresnet.pt (PyTorch State Dict)
   - Kiến trúc     : Mạng nơ-ron phần dư sâu (Deep Residual Network) tích hợp khối Self-Attention Head đa kênh để tự động trích xuất tương quan phi tuyến phức tạp giữa Glucose, HbA1c và BMI.
   - Hiệu năng     : ROC-AUC = 0.9793 (XUẤT SẮC NHẤT TOÀN BỘ HỆ THỐNG), Accuracy = 95.46%.

2. MÔ HÌNH 2: Super Stacking Meta-Learner (Học Kết Hợp Xếp Chồng)
   - Tệp lưu trữ   : project01/models/super_stacking_meta_learner.pkl
   - Kiến trúc     : Ensemble Stacking 2 cấp (Two-Level Architecture): Cấp 1 (Base Models) gồm Random Forest, Gradient Boosting, Decision Tree, MLP và Logistic Regression sinh xác suất Out-of-Fold. Cấp 2 (Meta-Learner) là hồi quy logistic tối ưu hóa biên độ quyết định.
   - Hiệu năng     : ROC-AUC = 0.9778, Accuracy = 97.14%.

3. MÔ HÌNH 3: Gradient Boosting Decision Trees - GBDT (Tăng Cường Gradient)
   - Tệp lưu trữ   : project01/models/diabetes_gradient_boosting.pkl
   - Kiến trúc     : Tập hợp 100 cây quyết định kế tiếp nhau sửa chữa sai số (Residuals) với tốc độ học learning_rate = 0.1 và max_depth = 4.
   - Hiệu năng     : ROC-AUC = 0.9788, Accuracy = 97.18%.

4. MÔ HÌNH 4: Deep Learning Multi-Layer Perceptron - MLP (Mạng Nơ-ron Nhiều Lớp)
   - Tệp lưu trữ   : project01/models/diabetes_mlp.pkl (Kèm diabetes_mlp_weights.npz)
   - Kiến trúc     : Mạng truyền thẳng 3 lớp ẩn (Dense 64 -> Dense 32 -> Dense 16), hàm kích hoạt ReLU, chuẩn hóa Batch Normalization và Dropout 0.3 chống quá khớp (Overfitting).
   - Hiệu năng     : ROC-AUC = 0.9774, Accuracy = 97.18%.

5. MÔ HÌNH 5: 1D-Convolutional Neural Network - 1D-CNN (Mạng Nơ-ron Tích Chập 1D)
   - Tệp lưu trữ   : project01/models/diabetes_cnn.pkl (Kèm diabetes_cnn_weights.npz)
   - Kiến trúc     : Sử dụng các bộ lọc tích chập 1D (Kernel Size 3, 32 Filters) quét qua không gian đặc trưng lâm sàng để phát hiện mẫu cục bộ giữa huyết áp, tim mạch và tuổi.
   - Hiệu năng     : ROC-AUC = 0.9773, Accuracy = 97.11%.

6. MÔ HÌNH 6: Recurrent Neural Network - LSTM Gating (Mạng Nơ-ron Hồi Quy LSTM)
   - Tệp lưu trữ   : project01/models/diabetes_lstm.pkl (Kèm diabetes_lstm_weights.npz)
   - Kiến trúc     : Cơ chế cổng nhớ Long Short-Term Memory (Forget Gate, Input Gate, Output Gate) mô phỏng động học điều tiết chuyển hóa glucose.
   - Hiệu năng     : ROC-AUC = 0.9759, Accuracy = 97.11%.

7. MÔ HÌNH 7: Random Forest Classifier (Rừng Cây Quyết Định)
   - Tệp lưu trữ   : project01/models/diabetes_random_forest.pkl
   - Kiến trúc     : Bagging Ensemble gồm 100 cây quyết định độc lập, phân bổ ngẫu nhiên tập con đặc trưng (Sub-feature Sampling).
   - Hiệu năng     : ROC-AUC = 0.9748, Accuracy = 97.23%.

8. MÔ HÌNH 8: Decision Tree Classifier (Cây Quyết Định Lâm Sàng)
   - Tệp lưu trữ   : project01/models/diabetes_decision_tree.pkl
   - Kiến trúc     : Cây quyết định đơn có chiều sâu tối đa max_depth = 8, dùng tiêu chí Gini Impurity, cho phép hiển thị luật suy diễn y khoa rõ ràng.
   - Hiệu năng     : ROC-AUC = 0.9738, Accuracy = 97.20%.

9. MÔ HÌNH 9: Scratch NumPy Logistic Regression (Kiểm Toán Đẳng Cấu Toán Học)
   - Tệp lưu trữ   : project01/models/diabetes_logistic_regression.pkl
   - Kiến trúc     : Mô hình được lập trình thủ công hoàn toàn từ đầu (From Scratch) bằng thư viện toán học thuần NumPy, không sử dụng framework Scikit-Learn hay PyTorch.
   - Kiểm toán     : Đối chiếu với Scikit-Learn và PyTorch đạt độ lệch tuyệt đối Delta = 0.0025 (< 0.005), chứng minh tính toàn vẹn toán học và loại bỏ rủi ro "Black-Box".
   - Hiệu năng     : ROC-AUC = 0.9620, Accuracy = 96.03%.

- Tác tử Học tăng cường D3QN (Reinforcement Learning Lifestyle Coach):
  + Tệp lưu trữ : project01/models/rl_dqn.pt (Mô hình PyTorch) & rl_qtable.json
  + Chức năng   : Dueling Double Deep Q-Network mô phỏng thời gian thực việc can thiệp chế độ ăn MNT và vận động để tối đa hóa thời gian trong ngưỡng TIR (Time-in-Range: 70 - 180 mg/dL).

PHẦN 4: HỆ THỐNG ĐA TÁC TỬ CHUẨN TẮC (HYBRID MAS - 8 AGENTS)
================================================================================
Tuân thủ tuyệt đối đặc tả kiến trúc: project_architecture_multiagent_diabet_v1.pdf (PTIT 11/2026).

1. KIẾN TRÚC 6 TẦNG (6-LAYER ARCHITECTURE):
   - Layer 1: User Interaction Layer (Web Dashboard, Natural Intake Chat Agent, RESTful API consumers).
   - Layer 2: API & Data Processing Layer (FastAPI routers, Pydantic data contracts, input sanitization).
   - Layer 3: Multiagent Coordination Layer (CoordinatorAgent A_coord điều phối tuần tự theo Mục 5.3).
   - Layer 4: Intelligent Agent Layer (8 Tác tử chuẩn tắc: A_data, A_DL, A_rule, A_KG, A_coord, A_exp, A_monitor, A_RL).
   - Layer 5: Knowledge & Model Layer (DB_diabet.cypher 56 thực thể Neo4j, mô hình TabResNet Attention PyTorch, VirtualPatientEnv D3QN).
   - Layer 6: Evaluation & Audit Layer (Giám sát độ trễ SLA, kiểm toán sai lệch |y_DL - y_rule|, cảnh báo cực trị và Section 10 Safety Disclaimers).

2. 8 TÁC TỬ CHUẨN TẮC (CANONICAL AGENTS):
   - A_data (PatientDataAgent)  : Tiền xử lý, chuẩn hóa và kiểm định dữ liệu đầu vào.
   - A_DL (DLPredictionAgent)   : Suy luận mạng nơ-ron học sâu TabResNet kết hợp cơ chế Self-Attention.
   - A_rule (RuleBasedAgent)    : Hệ suy luận biểu tượng dựa trên ngưỡng chuẩn ADA 2024 và KDIGO.
   - A_KG (KGRAGAgent)          : Truy xuất bằng chứng đồ thị tri thức DB_diabet.cypher (56 thực thể).
   - A_coord (CoordinatorAgent) : Điều phối đa tác tử và tổng hợp quyết định F(y_DL, y_rule, y_KG, y_monitor).
   - A_exp (ExplanationAgent)   : Tổng hợp giải thích lâm sàng grounded dựa trên bằng chứng minh bạch.
   - A_monitor (MonitoringAgent): Giám sát hiệu năng, độ trễ và phát hiện xung đột giữa AI và Quy tắc.
   - A_RL (RLSimulationAgent)   : Mô phỏng động học đường huyết 24h bằng MDP M_RL và Dueling Double DQN.

3. HỢP ĐỒNG THÔNG ĐIỆP CHUẨN HÓA:
   m_i = (id, agent, status, payload, evidence, version)

4. BÁO CÁO HỖ TRỢ QUYẾT ĐỊNH (DECISION SUPPORT REPORT):
   DecisionSupportReport = (Prediction + Evidence + Limitations)
